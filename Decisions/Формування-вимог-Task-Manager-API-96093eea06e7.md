# Формування вимог Task Manager API

Коміт «set requirements» додає дві початкові специфікації: docs/app-requirements.md описує локальний однокористувацький Task Manager API на FastAPI/SQLite, модель завдання, CRUD, пошук, фільтри, статистику та нефункціональні критерії; docs/harness-requirements.md визначає вимоги до agent harness, джерел даних і vault через MCP, guardrails, автономних сценаріїв та оцінювання. Обидва документи задають план і критерії майбутньої реалізації, а не реалізований функціонал.
