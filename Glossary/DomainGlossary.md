# Глосарій предметної області

| Термін | Визначення | Нотатка |
| --- | --- | --- |
| Завдання (Task) | Окрема запланована дія користувача | [[Task]] |
| Статус (status) | Поточний стан виконання завдання | [[TaskStatus]] |
| Пріоритет (priority) | Важливість завдання | [[TaskPriority]] |
| Дедлайн (due_date) | Бажана календарна дата виконання | [[DueDate]] |
| Життєвий цикл | Створення, зміна й видалення завдання | [[TaskWorkflow]] |
| Пошук | Вибір за фрагментом назви або опису | [[TaskSearchAndFiltering]] |
| Пагінація | Часткове отримання набору записів за limit/offset | [[TaskSearchAndFiltering]] |
| Статистика | Кількості завдань за статусами та всього | [[TaskStatistics]] |

Терміни збігаються з вимогами ПР1; нові значення не вводяться без зміни специфікації.
